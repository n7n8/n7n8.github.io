📋 特性

  • 使用 prefers-color-scheme 自动适配系统深色/浅色设置
  • 通过 color-scheme 属性让浏览器原生控件也适配
  • 所有颜色使用 CSS 变量，易于维护和扩展
  • 平滑的过渡效果
  • 包含手动切换按钮作为演示（实际项目可根据需求取舍）

🔧 如何实现的？

核心是以下 CSS：

@media (prefers-color-scheme: dark) {
  :root {
    --bg: #121212;
    --text: #e0e0e0;
    /* ...其他变量 */
  }
}

同时，在 body 上使用 color-scheme: light dark 让浏览器知道页面支持两种模式。
